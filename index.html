Расчёт колонок и фиктивных скважин

Колонки из DXF, координаты из каталога выработок и ось трассы собираются в одну таблицу для САПР. Между скважинами с шагом больше заданного добавляются фиктивные: слои интерполируются, X и Y берутся с оси по ПК.

Формат таблицы

Пример формата. Расчёт заполнит такую же таблицу: имя и отметка повторяются в каждой строке слоя, ГИЭ с буквой остаётся текстом, X, Y и ПК записаны текстом.

Как считаются слои. На каждом ПК берётся одна скважина: ближайшая к оси, при равенстве без «+15», затем первая по каталогу. Одинаковые ИГЭ у двух соседей интерполируются по мощности линейно, ИГЭ только у одного соседа выклинивается. Мощность слоя всегда берётся из подписи, глубины не используются. Расстояние считается только по ПК: 120+19 = 12019 м.

Методика. Между соседними исходными ПК создаётся минимальное число равных промежутков не длиннее заданного шага. При равном числе слоёв интерполируются мощности по порядку. При разном числе отсутствующие слои выклиниваются к середине интервала. Отметки Z фиктивных скважин линейно интерполируются между исходными по ПК. Неоднозначные ИГЭ помечаются для проверки.
